# InfoSlides MCP 1.7.4

A new tool for adding a text slide without AI, a corrected server version, and a skill that matches what the tools actually accept.

## New

- **`add_designed_slide`.** Adds a slide made of words to a slideshow: a `heading`, optional `text` and `cta`, and a background. The background is a hex colour (`backgroundColor`), an image from the media library (`mediaAssetId`) or an image URL (`mediaUrl`). With none, the workspace accent colour is used, and the text colour is chosen so it stays readable. The slide is drawn at the screen's size from fixed layouts, so the words appear exactly as written, no AI model is called and no AI credits are used. Text that is too long for the layout is refused with the field named and the number of characters that fit, instead of being cut off; how much fits depends on the layout and the screen (the table is in `making-slides.md`). The words are shown as given and are not checked for accuracy, and when the layouts do not offer enough flexibility (a table, columns, a look of their own) the way to go is a finished image added with `add_media_slide`.
- **A picture beside the text.** `imageMediaAssetId` or `imageUrl` puts a separate picture next to the text, over any background. The layout is picked from the fields given: `heading`, `heading-text`, `heading-text-cta`, `heading-image-right` or `heading-image-left`, or name one with `layout`. `branding: true` adds the workspace logo and accent colour (nothing is added for a workspace without a logo). `position` works as on `add_media_slide`, `durationSeconds` is 1 to 99, and the call returns the slide id, a design id, a preview link and an undo token.
- **Hosted profile.** The tool is in the hosted tool list, so ChatGPT, Claude, Microsoft 365 Copilot and Muse are offered it on the hosted server, with a hosted description that names no other tool. The hosted server now lists one more tool than in 1.7.3.

## Fixed

- **The hosted server reported version 1.0.0.** The `initialize` answer of `https://infoslides.app/mcp` carried a hard-coded version. It now reports the real one. The version has a single source, the CLI project's `<Version>`, which the host project reads, so the CLI and the host cannot drift apart again.

## Skill

The InfoSlides assistant skill that ships with the Claude plugin, the Gemini extension and the local program was corrected after an agent test run:

- **MCP arguments are flat.** A new table maps the REST bodies the reference files show to the flat arguments the tools take (`clockEnabled`, `tickerEnabled`, `width` and `height`). The nested form was accepted and changed nothing.
- **File uploads.** The file tools read a path on the machine running the local program. The remote host has none of them, so the skill now points at the REST multipart routes there.
- **Honest promises.** Undo is described as available on most calls, with what to do for the rest. "Ready" on a photo shown on a screen means prepared, not displayed; an open player switches within a minute or two. An ambiguous date like "on 6 January" is now asked about. The quota check uses `get_workspace_health`.
- **Also added:** how to find the source behind a live slide, the `data_trigger` condition syntax, the feedback field limits, a consent step before leaving a testimonial, and `add_designed_slide` as the first choice for a slide that is only words.

## Under the hood

- A new test reads the skill's argument table and fails if a name is not a real parameter of the tool it is listed under.
- Tool count assertions are updated for the new tool. The hosted and Muse profile tests cover it.
- The skill copies in `skills/` and `plugins/claude/skills/` and the hosted rules were re-synced from the InfoSlides repository with `scripts/sync-skills.py`.

## Upgrade

`add_designed_slide` calls `POST /v1/slideshows/{id}/slides/design`, which the InfoSlides API added in the same change set; against an older API the tool answers a not-found error. The local `infoslides` program, the Gemini CLI extension and the Claude and Antigravity plugins pick up the tool and the skill changes with the 1.7.4 build for your platform below. The hosted server at `https://infoslides.app/mcp` picks them up when it is redeployed, with nothing to do on your side. Your existing API keys and configuration keep working.
