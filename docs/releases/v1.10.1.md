# InfoSlides MCP 1.10.1

Hosted wording fixes for the ChatGPT directory review. No tool, parameter or result changed.

## Changed

- **Hosted server instructions.** The text hosted directories receive no longer tells the model to use the tools whenever a screen is mentioned, no longer asks it to check platform notices now and then, and no longer says that a workspace admin can change the plan. When a warning or error cannot be fixed, the model passes its message on in plain words. The text comes from the website's skill source.
- **`create_device` and `make_ai_slide` (hosted descriptions).** The sentence saying a workspace admin can change the plan is gone. The descriptions now say to pass the `DeviceLimitReached` or `EntitlementRequired` message on, and `make_ai_slide` no longer lists prices as an example of what a slide can hold. The API's error messages are unchanged.
- **README.** The Linux quickstart downloads the file named for the current version; the 1.10.1 pin had kept the 1.10.0 file name.
