# InfoSlides MCP 1.7.3

The hosted server now recognises Muse, Meta's assistant, and offers it a smaller set of tools.

## New

- **Muse tool profile.** A caller that connects through Muse is not offered the three AI slide tools (`make_ai_slide`, `get_ai_slide_job` and `insert_ai_slides`), and a call to one of them by name is refused. Every other tool stays. Muse is recognised from its OAuth client, so no other assistant changes: ChatGPT, Claude, Microsoft 365 Copilot and Gemini keep the tools they had.
- **Muse instructions.** The instructions the server sends to Muse no longer suggest `make_ai_slide` for photos, since Muse cannot call it.

## Under the hood

- The tool list and the call filter share one check, `HostedToolProfile.IsOffered`, so what is listed and what is allowed cannot disagree.
- New tests cover the Muse tool list, refusal by name, and the Muse instructions.

## Upgrade

The local `infoslides` program, the Gemini CLI extension and the Claude and Antigravity plugins behave as in 1.7.2; download the 1.7.3 build for your platform below if you want the matching version number. The hosted server at `https://infoslides.app/mcp` picks the change up when it is redeployed, with nothing to do on your side. Your existing API keys and configuration keep working.
