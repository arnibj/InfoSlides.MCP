# InfoSlides MCP 1.10.3

Answers to the OpenAI directory scan, which flagged four tools as marked non-destructive while they can overwrite or replace something. OpenAI's plugin guidelines (6.3) count overwriting as destructive and say an undo alone does not make a tool non-destructive. No parameter or result shape changed.

## Fixed

- **`update_slideshow`, `update_slide`, `pair_device` and `update_source_settings` are now marked destructive** (`destructiveHint: true`), so ChatGPT and other clients ask before calling them.
- **Hosted descriptions say what can be put back.** `update_slideshow` and `update_slide`: the result's undo restores the previous settings, slide order or slide within 24 hours. `pair_device`: the undo removes a new screen, or disconnects the TV from an existing screen, and a TV that was replaced has to be paired again. `update_source_settings`: `config` replaces the whole stored config and there is no undo.

## Directory listings

Four hosted tools changed. Rescan in the OpenAI portal after the host is redeployed. `get_device_diagnosis` and `get_workspace_health` are new tools waiting for OpenAI's review; nothing changes for them.

## Upgrade

Redeploy the hosted server. The InfoSlides website API is unchanged. Local installs keep working; update to get the new hints.
