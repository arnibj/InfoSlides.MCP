# InfoSlides MCP 1.10.0

`check_slideshow` now describes the full check the website runs, and agents are told what it can find.

## New

- **Check a slideshow looks further.** `check_slideshow` now also reports content in a source that has all expired, a media file that is missing, a visibility rule whose dates have passed so its slides never show, a screen of the other orientation, and text that is too small to read or gets cut off. New finding codes: `ContentExpired`, `MediaMissing`, `SlideExpired`, `AspectMismatch`, `TextTooSmall`, `TextOverflow` and `TextNotFullyChecked` (some slides could not be measured). The check lays slides out to measure their text, so it can take some seconds. The checks come from the website API; this release corrects the tool's description, which said they were not done.
- **Takeover list pages.** `list_takeovers` now returns `items`, `total`, `page`, `pageSize` and `totalPages`, with the 50 latest takeovers and the total. This comes from the website API.
- **Evening version.** New tools `get_evening_version_offer` and `make_evening_version` (CLI: `slideshow evening-offer` and `slideshow evening`; hosted callers get `make_evening_version` only): one call makes a dark copy of a slideshow, named with "(evening)" after the title, and plays it on the same screens every evening, by default from 17:00 until 08:00 in the workspace timezone. The result names the copy and the times on each screen, and `undo_change` deletes the copy. This comes from the website API.
- **Skill.** The "Is this slideshow ready?" guidance in the local and Claude plugin skills matches the new check.

## Under the hood

- Dependabot checks monthly instead of weekly.

## Directory listings

One hosted tool is added: `make_evening_version`. The hosted description of `check_slideshow` also changed. Refresh the tool list and descriptions in each directory submission that shows them (Claude, ChatGPT, Microsoft) after the host is redeployed.

## Upgrade

Deploy the website API first, then the hosted server: until the website is updated, the new description promises checks the API does not yet run, and the evening tools answer `NotFound`. No client has to upgrade to keep working. `list_takeovers` passes the API's JSON through, so its new shape reaches every version, and a program that reads that result directly must read `items` instead of a bare list.
