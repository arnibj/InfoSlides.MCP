# InfoSlides MCP 1.7.2

InfoSlides now installs in Google's Antigravity CLI as a plugin, and the install steps for Antigravity are corrected.

## New

- **Antigravity plugin.** The repository root is now an Antigravity plugin: a `plugin.json`, an `mcp_config.json` that runs the local `infoslides` program in MCP mode, and the Digital Signage Assistant skill. Install it from a copy of the repository:
  ```sh
  git clone https://github.com/arnibj/InfoSlides.MCP
  agy plugin install ./InfoSlides.MCP
  ```
  Check it with `agy plugin list`, which should show `infoslides` with `skills` and `mcpServers`. Antigravity installs plugins from a folder on your computer, so this takes two commands, unlike the one-line install for Gemini CLI.
- **Before you install,** you need two programs on your computer:
  - the Antigravity CLI, `agy`: `irm https://antigravity.google/cli/install.ps1 | iex` on Windows, or `curl -fsSL https://antigravity.google/cli/install.sh | bash` on macOS and Linux;
  - the `infoslides` program from the [latest release](https://github.com/arnibj/InfoSlides.MCP/releases/latest), on your PATH.
- **Signing in.** Run `infoslides auth login` once, or set the `INFOSLIDES_API_KEY` environment variable before you start `agy`. Keep the key out of the repository and out of `mcp_config.json`.

## Fixed

- **The Antigravity command in the README was wrong.** It said `agy plugin import gemini <address>`. That command only imports extensions that are already installed in Gemini CLI and takes no address, so it could not install InfoSlides. The README and `GEMINI.md` now show the install above.

## Under the hood

- **Tests no longer depend on your machine's environment.** The "no credential" smoke test started the server without a key but inherited an `INFOSLIDES_API_KEY` exported on the machine, so it failed for anyone who had one set. The test now removes the variable from the server it starts.
- The README test now checks for the Antigravity install command, and that the wrong `import` line is gone.

## Upgrade

Download the 1.7.2 build for your platform below, or pull the repository and reinstall the Antigravity plugin with `agy plugin install ./InfoSlides.MCP`. Gemini CLI users: `gemini extensions install https://github.com/arnibj/InfoSlides.MCP` is unchanged. The hosted server at `https://infoslides.app/mcp` is not affected by this release.
