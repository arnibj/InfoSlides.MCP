# InfoSlides MCP 1.7.1

A small release that makes the tool descriptions and parameters cleaner for the assistant directories that list the hosted server. Nothing changes in what you can do with your screens.

## Improved

- **Typed JSON parameters.** Tools that take a JSON object now declare it as an object in their schema: the data for `push_data` and `update_source`, and the field mapping, override data and countdown for `update_slide`. The same applies to the example data and config of `create_template`, `create_source`, `update_source_settings` and `preview_new_template`. Assistants and directory checks can now see what shape each argument has.
- **Plain descriptions on the hosted server.** The tool descriptions that ChatGPT, Claude and Microsoft 365 Copilot see now only describe what each tool does, takes and returns. Guidance on how to work, such as asking before deleting something and offering undo, lives in the server instructions and the skill. The local server keeps its full descriptions.
- **`list_devices` on the hosted server** no longer mentions a location filter that the hosted server does not offer.

## Changed

- **`update_slide` takes `countdown` as an array.** It used to accept a single countdown object as well. If you send one countdown, wrap it in an array: `[{...}]`. An empty array still clears the countdowns.
- **CLI `--config` and `--sample-data` must be a JSON object**, inline or from `@file`. Anything else is now rejected with a clear message.

## Under the hood

- Two new tests guard this: one fails if any tool parameter has no schema type, the other fails if a hosted description names another tool or addresses the assistant.
- `docs/hosted-directory-rules.md` records the rules for hosted tool text and how to add a hosted tool.

## Upgrade

Download the 1.7.1 build for your platform below, or update the Gemini extension or Claude plugin. The hosted server at `https://infoslides.app/mcp` picks the change up when it is redeployed, with nothing to do on your side. Your existing API keys and configuration keep working.
