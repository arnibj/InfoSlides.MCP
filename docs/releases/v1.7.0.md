# InfoSlides MCP 1.7.0

This release takes InfoSlides beyond the desktop. You can now manage your screens from the AI assistants you already use on the web, with your InfoSlides account and no API key.

## New

- **Hosted MCP server at `https://infoslides.app/mcp`.** Add it as a custom connector in ChatGPT, Claude or Gemini and connect straight to your InfoSlides workspace. You sign in with your InfoSlides account (OAuth) and approve the connection, and you can disconnect an app at any time from your account settings. API keys still work for clients that use them.
- **Claude plugin.** Uses the hosted server, so there is nothing to download:
  ```sh
  claude plugin marketplace add arnibj/InfoSlides.MCP
  claude plugin install infoslides@infoslides
  ```
- **Gemini CLI extension and Antigravity plugin.** Runs the local server with the full toolset:
  ```sh
  gemini extensions install https://github.com/arnibj/InfoSlides.MCP
  agy plugin import gemini https://github.com/arnibj/InfoSlides.MCP
  ```
- **ChatGPT plugin.** Published at `https://infoslides.app/plugins/chatgpt/`, ready for the ChatGPT directory listing.

## Improved

- **Safer actions.** Every tool now tells the assistant whether it only reads, makes changes, can delete or replace content, or reaches outside InfoSlides. Assistants use this to ask before deleting a slideshow, replacing a schedule or taking over a screen.
- **A focused tool set for web assistants.** ChatGPT, Claude and other hosted assistants get the tools for everyday screen work: what is playing, slides, schedules, tickers, live data and AI Studio slides. Billing, account creation and API key management stay in the InfoSlides dashboard. The local server keeps every tool.
- **Digital Signage Assistant skill.** Rewritten in two versions, one for the local server and one for web assistants, each naming only the tools it can use. New guides cover common scenarios, everyday edits, live data and AI Studio.

## Security

- Your credentials pass through to InfoSlides on each request, and the hosted server stores none of them. The InfoSlides API enforces permissions, plan limits and undo, exactly as it does in the dashboard.
- The hosted server cannot read files from its own disk. Uploading a file by path only works with the local server, on your own computer.
- Rate limits apply per connection rather than per network address, so assistants that share cloud networks do not slow each other down.

## Upgrade

Download the 1.7.0 build for your platform below, or update the Gemini extension or Claude plugin. Your existing API keys and configuration keep working.
